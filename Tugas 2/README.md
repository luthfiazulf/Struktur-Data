 # Implementasi Stack (Tumpukan) dalam Java

Stack (tumpukan) adalah struktur data linear yang mengikuti prinsip LIFO (Last In, First Out), di mana elemen terakhir yang dimasukkan adalah yang pertama kali dikeluarkan. Data hanya bisa ditambah (push) atau dihapus (pop) dari satu ujung yang disebut Top (puncak).
